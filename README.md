# apin

Benchmarking + sampler-engineering project: cmdstan 2.39 kernel work and
walnutpie (WALNUTS) adaptation/correctness work, on a 21-model posteriordb
core set. See `stan/WORKLOG.md` (experiment log) and
`stan/results/FINAL_REPORT.md` (consolidated report); `HANDOFF.md` to start a session (queued work, protocol, gotchas); `BOOTSTRAP.md` for environment setup; `NEXT_IDEAS.md` for open ideas.

External repos are submodules pinned to the exact SHAs used:
walnutpie (fork, dev/init-robustness), cmdstan (fork, nindan/mixed-build-guard),
posteriordb (upstream @ 28f8d3d6), tinystan (upstream).
